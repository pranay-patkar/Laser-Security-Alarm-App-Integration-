HC-05 RX VOLTAGE PROTECTION — DETAILED EXPLANATION

⚠ CRITICAL — HARDWARE DAMAGE RISK
The Arduino Uno operates at 5V logic. The HC-05/HC-06 Bluetooth module's RX pin is rated for a maximum of 3.3V. Connecting D11 (TX) directly to HC-05 RX will damage the Bluetooth module over time and may destroy it immediately.

VOLTAGE DIVIDER CALCULATION

// Resistor values: R1 = 1kΩ, R2 = 2kΩ
//
//  D11 ──[R1=1kΩ]──┬── HC-05 RX
//                  │
//               [R2=2kΩ]
//                  │
//                 GND
//
// V_out = V_in × R2 / (R1 + R2)
// V_out = 5V  × 2000 / (1000 + 2000)
// V_out = 5V  × 0.6667
// V_out = 3.33V  ✓ (within 3.3V spec)

ALTERNATIVE: LOGIC LEVEL CONVERTER

For a cleaner solution, use a bi-directional logic level converter module (BSS138-based):


  • LV side → 3.3V + Arduino TX
  • HV side → 5V + HC-05 RX
  • Works at all baud rates without signal degradation
  • Protects both directions automatically
  • Costs ~$1 on breakout boards

HC-05 INITIAL CONFIGURATION (AT COMMANDS)

ℹ BEFORE FIRST USE
Hold the HC-05 EN button while powering on to enter AT mode. Connect TX/RX directly to Arduino (no voltage divider needed for AT mode config). Use Serial Monitor at 38400 baud. 
// AT Command sequence to configure HC-05
AT                         → OK  (test connection)
AT+NAME=SENTINEL           → OK  (set device name)
AT+PSWD=1234               → OK  (set PIN code)
AT+UART=9600,0,0           → OK  (set baud to match firmware)
AT+ROLE=0                  → OK  (Slave mode — waits for connection)
AT+RESET                   → OK  (restart in normal mode)

// HC-06 uses different AT syntax (no newline needed):
// AT+NAMESENTINEL
// AT+PIN1234
// AT+BAUD4  (4 = 9600 baud)

CALIBRATION & TROUBLESHOOTING

BEAM ALIGNMENT

  • Position laser 1–5m from LDR
  • Use a cardboard mount or 3D-printed bracket
  • Aim beam at LDR center for maximum sensitivity
  • Shield LDR from ambient light with a short tube

THRESHOLD TUNING

  • Open Serial Monitor at 9600 baud
  • Note CAL:BASELINE= value on boot
  • Manually break beam, observe ADC drop
  • Set BEAM_BREAK_THRESHOLD to ~70% of that drop
  • Typical: baseline ~850, break ~300, threshold 150

COMMON ISSUES

  • No BT connection → check baud rate matches AT config
  • False alarms → increase threshold or shield LDR
  • Buzzer always on → SoftwareSerial pin conflict; avoid pins 0,1
  • HC-05 not pairing → enter AT mode, verify ROLE=0
  • Web Serial not working → must use Chrome/Edge, HTTPS required for deployment
